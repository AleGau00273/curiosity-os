CURIOSITY OS — Portfolio Website
================================

A personal portfolio for Alexander Gaudet, featuring software development and hardware restoration projects.

FILES
- index.html: main website
- css/style.css: website styling
- js/app.js: interactive console and project galleries
- assets/images/projects/: project screenshots and photos
- assets/videos/: local demonstration videos

LOCAL PREVIEW
Open the project folder in VS Code and use Live Server, or serve the folder using a local HTTP server. Open index.html and verify the carousels, images, and videos.

GITHUB PAGES
1. Upload the entire site, preserving its folder structure, to a GitHub repository.
2. In repository Settings > Pages, choose Deploy from a branch and select the branch and root folder (/).
3. Wait for publication, then test the live site on desktop and mobile.
4. Keep the assets/ folders: project images and videos are local dependencies.

EXTERNAL DEPENDENCIES
Bootstrap and any other CDN resources referenced in index.html require an internet connection.

CONTROLS
The console carousel has previous/next buttons, navigation dots, and a pause/play button. Autoplay is disabled when reduced motion is requested. Project galleries use manual controls.

- Explore Australia (collaborative responsive web project)
